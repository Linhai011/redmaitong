# 红脉通 · 数据库设计文档（数据字典）

> 对应脚本：`01_schema.sql`（建表）、`02_seed.sql`（示例数据）
> 数据库：`redmaitong`　字符集：`utf8mb4`　引擎：`InnoDB`　MySQL 版本：8.0

## 1. 设计约定

| 项目 | 约定 | 说明 |
| :--- | :--- | :--- |
| 命名 | 表名/字段名一律 `snake_case` 小写 | 如 `share_auth`、`resource_id` |
| 主键 | `BIGINT UNSIGNED AUTO_INCREMENT` | 代理键，与业务编码（ORG001 等）解耦 |
| 外键 | `FOREIGN KEY ... ON DELETE ...` | 明确删除策略，保证数据完整性 |
| 时间 | `DATETIME` + `DEFAULT CURRENT_TIMESTAMP` | `updated_at` 用 `ON UPDATE` 自动维护 |
| 状态/等级 | `TINYINT` 数字编码 | 取值在注释中说明，个别用 CHECK 约束 |
| 多对多 | 独立关联表 + 复合主键 | 如 `resource_tag`、`exhibition_org` |

## 4. 表关系说明

| 关系 | 涉及表 | 基数 | 实现方式 |
| :--- | :--- | :--- | :--- |
| 机构 ↔ 用户 | org ↔ sys_user | 1 : N | `sys_user.org_id` 外键 |
| 机构 ↔ 资源 | org ↔ resource | 1 : N | `resource.org_id` 外键 |
| 分类 ↔ 资源 | resource_category ↔ resource | 1 : N | `resource.category_id` 外键 |
| 分类 ↔ 分类 | resource_category 自关联 | 1 : N | `resource_category.parent_id` |
| 资源 ↔ 文件 | resource ↔ resource_file | 1 : N | `resource_file.resource_id` 外键 |
| 资源 ↔ 标签 | resource ↔ tag | N : N | 中间表 `resource_tag` |
| 展馆 ↔ 机构 | exhibition ↔ org | N : N | 中间表 `exhibition_org` |
| 展馆 ↔ 资源 | exhibition ↔ resource | N : N | 中间表 `exhibition_resource` |
| 用户 ↔ 资源（收藏/下载/浏览） | sys_user ↔ resource | N : N | 三张行为表 |
| 资源/机构/用户 ↔ 授权申请 | share_auth | N : N | 双机构外键 + 资源外键 |

> 完整 ER 图（mermaid）见 `README.md`。

## 6. 数据库对象清单（进阶，见 `04_advanced.sql`）

### 6.1 视图（VIEW）

### 6.2 存储过程（STORED PROCEDURE）

| 名称 | 参数 | 说明 |
| :--- | :--- | :--- |
| sp_pending_auth | IN p_org_id | 查某机构收到的待审批申请 |

### 6.3 触发器（TRIGGER）

| 名称 | 时机 | 作用 |
| :--- | :--- | :--- |
| trg_download_count | download_record 插入后 | resource.download_count 自动 +1 |
| trg_browse_count | browse_history 插入后 | resource.view_count 自动 +1 |

### 6.4 全文索引（FULLTEXT）

| 名称 | 所在表 | 覆盖列 | 分词器 |
| :--- | :--- | :--- | :--- |
| ft_resource_search | resource | title, meta_desc | ngram（中文按 2 字切词） |

> 使用方式：`MATCH(title, meta_desc) AGAINST('关键词' IN NATURAL LANGUAGE MODE)`，支持中文全文检索与相关度排序，对应原型首页的跨机构检索框。
